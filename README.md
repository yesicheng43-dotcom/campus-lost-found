# 校园失物招领

2026 秋软件工程结对作业：校园失物招领程序实现。

## 项目说明

本项目根据 Figma 原型实现校园失物招领 Web 应用，覆盖浏览、搜索、发布、详情和个人发布管理等核心流程。

技术栈：Python 3.10+ / Flask 3.x / SQLite / Jinja2 / 原生 HTML + CSS + JavaScript / pytest。

## 目录结构

```text
campus-lost-found/
├── app/                       # 应用核心代码
│   ├── __init__.py            # 应用工厂：创建 Flask 实例、注册蓝图、注入当前用户、处理 404
│   ├── db.py                  # 数据访问层：SQLite 连接管理、建表与种子数据、各项增删改查
│   ├── schema.sql             # 数据库表结构（users / items）
│   ├── validation.py          # 常量与表单校验（发布类型、状态选项、必填项规则）
│   └── views.py               # 路由层：页面路由、登录校验装饰器、权限判断
├── static/                    # 静态资源
│   ├── css/style.css          # 全局样式（手机竖屏优先，桌面浏览器中居中显示）
│   ├── js/app.js              # 前端交互（复制联系方式等）
│   └── assets/                # 图片素材：校园背景、头像、物品图、发布类型卡片
├── templates/                 # Jinja2 页面模板（共 11 个）
│   ├── base.html              # 公共骨架：顶部标题栏、底部固定导航
│   ├── index.html             # 首页：信息列表 + 搜索框 + 类型筛选
│   ├── detail.html            # 信息详情：完整信息 + 联系方式
│   ├── publish_type.html      # 发布类型选择（寻物 / 招领）
│   ├── publish_form.html      # 发布表单（寻物与招领共用，仅文案不同）
│   ├── my_posts.html          # 我的发布：列表 + 状态更新入口
│   ├── profile_edit.html      # 修改个人邮箱与联系电话
│   ├── login.html             # 登录
│   ├── register.html          # 注册（代码保留，页面暂不提供入口）
│   ├── 404.html               # 友好的 404 页面
│   └── coming_soon.html       # 占位页
├── tests/
│   └── test_app.py            # 单元测试（16 个用例，覆盖核心流程与权限）
├── instance/                  # 运行时生成的 SQLite 数据库存放处（不提交到仓库）
├── AI_HANDOFF.md              # AI 开发交接文档：项目事实、决策与当前状态
├── PROJECT_RULES.md           # 项目协作与开发规范
├── README.md                  # 本文件
├── requirements.txt           # 依赖清单：Flask、pytest
└── run.py                     # 本地启动入口
```

各层职责一句话概括：`views.py` 只负责"接请求、判权限、选模板"，`db.py` 只负责"读写数据库"，`validation.py` 只管"校验规则"，`schema.sql` 管"表结构"。字段名在数据库、路由、模板和测试之间保持一致，改一处要同步改四处。

## 使用说明

### 1. 环境要求

- Python 3.10 及以上（开发时使用 3.10 / 3.11）
- 浏览器建议使用 Chrome（作业要求统一）
- 无需额外数据库服务，SQLite 随程序自动创建

### 2. 启动步骤

在项目根目录打开 PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

启动后浏览器访问 **http://127.0.0.1:5000/**。

> 如果 PowerShell 禁止激活虚拟环境（提示执行策略限制），可以跳过激活，直接：
> ```powershell
> .\.venv\Scripts\python.exe run.py
> ```

首次启动时会自动在 `instance/` 下创建 SQLite 数据库并写入演示数据，不需要手动初始化。

### 4. 功能操作指南

**浏览与搜索（无需登录）**

1. 打开首页即可看到全部失物招领信息，卡片左侧为物品图，右侧显示名称、类型、地点、日期和状态。
2. 顶部搜索框支持按**物品名称、地点、描述**三个字段模糊匹配，例如输入"雨伞"或"西区"。
3. 点击「寻物 / 全部 / 招领」切换类型筛选。

**查看详情与联系发布者（无需登录）**

1. 点击任意卡片进入详情页，可看到图片、名称、类型、状态、时间、地点、描述和联系方式。
2. 联系方式旁提供**一键复制**按钮。

**发布信息（需登录）**

1. 点击底部导航「发布」→ 选择「发布寻物」或「发布招领」。
2. 填写物品名称、类别、地点、时间、描述和联系方式（联系方式会自动带出当前账号的邮箱）。
3. 提交后若有必填项为空，表单会提示具体哪一项缺失，并保留已填内容；全部通过后跳转到新建信息的详情页。

**管理我的发布（需登录）**

1. 点击底部导航「我的」，查看自己发布的全部信息，可按类型筛选。
2. 在列表中选择新的状态（寻物：寻找中 / 已找到；招领：待认领 / 已归还）即可完成状态更新。
3. 普通用户只能修改自己发布的信息；管理员登录后可以看到并修改全部信息。

**修改联系方式（需登录）**

点击「我的」页面中的「编辑资料」，可修改邮箱和联系电话，修改后详情页展示的联系方式同步更新。

### 5. 运行单元测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

测试使用 Flask 测试客户端，会在临时目录创建独立的测试数据库，不污染本地演示数据。

### 6. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| PowerShell 无法激活虚拟环境 | 跳过激活，直接用 `.\.venv\Scripts\python.exe` 执行 |
| 想重置演示数据 | 删除 `instance/lost_found.sqlite3` 后重新启动，会自动重建 |
| 端口 5000 被占用 | 修改 `run.py` 中 `app.run()` 的 `port` 参数 |
| 页面样式不更新 | 浏览器强制刷新（Ctrl + F5）清除 CSS 缓存 |
